🔐 instgram-phishing-Demo

  **Security Awareness & Phishing Simulation Demo**


  
  
  


📌 About
instgram-phishing-Demo is an educational security awareness project designed to demonstrate how phishing-style login pages can look and why users should be careful when entering their credentials online.
This project is intended strictly for ethical cybersecurity education and authorized testing.
✨ Features

Modern, responsive demo login interface
Instagram-inspired visual design
Safe demonstration mode
No real passwords collected or stored
Optional Telegram notification for demo login attempts
Localhost support
Beginner-friendly setup

🛠️ Requirements

Windows 10 / Windows 11
XAMPP
PHP
MySQL (only if required by the demo)
Web browser

🚀 Installation

Download or clone this repository.

git clone https://github.com/LiveMedia48/instgram-phishing-Demo.git


Move the project folder into:

C:\xampp\htdocs\



Start Apache from XAMPP Control Panel.


Open your browser:


http://localhost/instgram-phishing-Demo/

🖥️ Run Using CMD
cd C:\xampp\htdocs\instgram-phishing-Demo

Then open the localhost URL in your browser.
🔔 Telegram Notifications
The demo can optionally send a notification when someone interacts with the demonstration page.
Notifications must not contain real passwords, authentication tokens, or other sensitive credentials.
🔒 Disclaimer
This project is created strictly for educational purposes, cybersecurity awareness, and authorized security testing.

Do not use it to impersonate real services for credential theft.
Do not collect or transmit real user passwords.
Do not deploy it against unsuspecting users.
